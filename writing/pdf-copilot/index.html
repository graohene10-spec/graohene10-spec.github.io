PDF Copilot：把 AI 放在 PDF 阅读旁边

Kerf599 字约 2 分钟
工具

阅读论文或教材时，遇到不熟悉的概念、复杂的公式或图表，常常需要把内容复制到另一个窗口再提问。PDF Copilot 是一个轻量的 Edge / Chrome 扩展，想让这一步更顺手：继续在浏览器里读 PDF，把 AI 对话放在旁边。

它提供两种阅读方式。日常可以保留浏览器自带的 PDF 阅读器，用侧栏或快捷键召出的临时窗口交流；需要直接操作文档时，则切换到基于 PDF.js 的增强阅读器，使用连续滚动、缩放、目录跳转、个人书签和夜间模式。

我比较看重的功能是选中内容再提问。文字可以直接作为附件；公式、图表和扫描内容可以用鼠标框选，预览后加入对话。在增强阅读器里，附件还保留页码，可以从对话跳回原位置。默认发行版自带公式渲染模块与字体，无需额外安装公式环境；发送后也会显示“AI 思考中…”并逐步呈现回答。

模型连接支持 DeepSeek、OpenAI API Key，以及通过可选 Windows 小助手复用本机 Codex CLI 登录；模型和思考强度可以调整。PDF 不会自动整本上传，只有主动发送的问题、选文、截图和会话上下文会交给所选服务。截图在内存中处理，工具不主动将它保存为本地图片文件。

目前已发布 v0.2.3，提供自带公式的默认版和体积更小的极简版，通过解压加载扩展安装。它适合边读边问，尚未提供整本知识库、OCR 或全文搜索；详细功能、安装教程与测试范围都写在仓库 README 中。
