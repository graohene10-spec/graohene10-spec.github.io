娥眉月 · 北半球示意

从半椭圆，算出亮面比例

当前 α = 120.0° · k = 25.0%

令月球半径为 R，z 轴指向地球，u 轴在画面中朝向明亮月缘，y 轴向上。当前 u 向右。 相位角 α 是月球处“指向太阳”与“指向地球”两条方向的夹角。

  1. 球面的交界线

    可见球面满足 z ≥ 0。表面法线 n 与太阳方向 s 垂直处，是昼夜分界。

    u² + y² + z² = R²
    u sin α + z cos α = 0

    受光条件 n · s > 0；可见条件 n · v > 0。边界处取等号。

  2. 一条亮带的宽度

    在高度 y 处，月盘半宽为 r(y)。解出朝向地球的交界线分支 T，再从月缘 L 减去它。

    r(y) = √(R² − y²)
    uT(y) = −cos α · r(y)
    w(y) = r(y) − uT(y)
    = (1 + cos α) r(y)
  3. 累加所有亮带

    将宽度乘以微小高度 dy，再从月盘底部积到顶部。√(R² − y²) 的积分是半圆面积。

    A亮 = ∫−RR w(y) dy
    = (1 + cos α) · πR² / 2
    k = A亮 / πR² = (1 + cos α) / 2

当 cos α ≠ 0，交界线的完整投影满足 u² / (R² cos²α) + y² / R² = 1，椭圆半轴为 R 与 R|cos α|；只有 z ≥ 0 的那一半可见。α = 90° 时退化成直线，所以弦月恰好亮一半；α = 0° 或 180° 时交界线与月缘重合，得到满月或新月。

i
月相不是地球的影子。 地球遮住阳光时发生的是月食。月球轨道相对地球公转轨道倾斜约 5°，所以并非每次满月都有月食。本模型采用太阳方向固定的匀速圆周相对运动，忽略食、轨道倾角、天平动与地面视差；尺寸与距离不按比例。月面方向为南／北半球典型示意，实际倾斜还随纬度和时刻变化。暗区被轻微提亮以显示轮廓，新月实际通常不可见。
